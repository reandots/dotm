# dotm

[English](../en/README.md) · [Корневой README](../../README.md)

## Назначение и границы

dotm разворачивает личное окружение приложений на разных дистрибутивах Linux. Nix управляет пакетами в стандартном пользовательском XDG-профиле, chezmoi — выбранными конфигурационными файлами. Home Manager не используется. Подготовка ОС, установка Nix, системные настройки, службы и интеграция с сеансом остаются задачами Ansible.

**Приложение** — логическая запись каталога: несколько пакетов, конфигурационные пути, хуки или только зависимости. **Конфигурация** — именованный набор для машины или сценария использования, а не дистрибутив Linux. Выбор приложения включает всех его транзитивных логических спутников; техническими зависимостями пакетов занимается Nix.

## Модель безопасности

Просмотр отделён от изменений. `install` не удаляет лишнее; `update` не устанавливает полностью отсутствующие независимые приложения. Удаление и очистка требуют подтверждения. Сборка мусора никогда не запускается неявно и может затронуть всё общее хранилище Nix.

Обновление пакетов имеет механизм восстановления, но общей транзакции для хуков и пользовательских данных нет. Применение конфигураций может завершиться частично: конфликтующие локальные файлы сохраняются. Хуки и файловые шаблоны chezmoi — доверенный код, а не изолированные входные данные. Перед работой с реальным состоянием изучите ограничения нужной операции.

Подробные контракты и результаты прежних проверок находятся в англоязычной [базе знаний](../../.agent/README.md). Английская и русская публичная документация поддерживаются эквивалентными; примеры с вымышленными репозиториями не предназначены для развёртывания.
